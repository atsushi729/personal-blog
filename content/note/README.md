# Note content

Place MDX notes under the locale and category path.

```text
content/note/en/ads/data-structure/tree/example.mdx
content/note/ja/ads/data-structure/tree/example.mdx
```

Supported category paths:

- `ads/data-structure/tree`
- `ads/data-structure/graph`
- `ads/algorithm`
- `ai/deep-learning`
- `ai/machine-learning`
- `ai/rag`

Each MDX file uses the same front matter shape as blog posts:

```mdx
---
title: "Tree Basics"
date: "2026-05-08"
locale: en
translationKey: tree-basics
excerpt: "Short summary"
---

Write the note here.
```
